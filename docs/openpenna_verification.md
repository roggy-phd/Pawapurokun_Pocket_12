# オーペナ検証：第三球種は最強選手をさらに強くするか？（16シーズン）

ROMパッチv28で作ったROMを使い、第三球種の有無や中身だけを変えた最強選手6人でオーペナを回した結果です。解説記事は[こちら](https://note.com/roggy_phd_games/n/nc6df5d0e5a81)。

## 検証条件

| 投手 | ベース | 第三球種（byte92上位4bit） |
|---|---|---|
| 最強0 | 旧最強（オリ変「オリジナル」） | なし |
| 最強4 | 旧最強 | セット4（基本5系統 Lv4） |
| 最強7 | 旧最強 | セット7（基本5系統 Lv7） |
| 最強G | 新最強（オリ変「ライジング」） | なし |
| 最強E | 新最強 | セットE（ストレートLv7のみ） |
| 最強F | 新最強 | セットF（カットボール／Dカーブ／チェンジアップ／Hシンカー／Hシュート Lv4＋ストレートLv7） |

- 6チーム（G、G2〜G6）に1人ずつ入れてオーペナ
- チーム割り当てを変えた4条件：条件1＝S1〜5、条件2＝S6〜8、条件3＝S9〜12、条件4＝S13〜16
- S14のみ、実際の割り当てが条件1と同じだったため、実際のチームで集計
- 交流戦で当たる別リーグのチームはペナントデータごとにランダムなので、完全に均等な配置にはできない

## まとめ

1. **防御率**：16シーズンでも第三球種による改善は見えない。むしろわずかに悪い方向（+0.1程度、有意ではない）。4−0のp=0.03も、比較の数を考えると偶然の範囲。
2. **奪三振**：第三球種があると少し減る方向で一貫。最強7（Lv7）が最もはっきりしていて約−0.35/9。前回の9シーズン検証（約−1.2/9）と同じ向きだが、大きさはずっと小さい。
3. **与四死球**：第三球種があると少し減る（約−0.14/9、チーム補正後もp=0.026）。チームの影響を除いても残った唯一の差。
4. 8シーズン時点の「最強G（ライジング）だけ四死球が多い」は、16シーズンで消えた（G−0はほぼ0）。
5. 全体として、**第三球種を足すと、三振と四球がどちらも少し減る「打たせて取る」投手になる。ただし失点は変わらない。**

## 注意点

- シーズンごとの防御率のばらつき（同じ投手同士の差のSD）は約0.35。16シーズンで見分けられるのは0.25前後の差までで、0.1程度の差は検出できない。
- 数値はスクリーンショットからの書き起こし。全96行で、自責点と投球回から計算した防御率が表示値と一致することを確認済み。
