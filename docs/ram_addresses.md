# パワポケ12（VPTJ）メモリ上の主なアドレス（ROM解析メモ）

ROMパッチ作成時の解析で確認した、試合中・メニュー中の主なアドレスです。アクションリプレイ（AR）などのコード作りの参考にもなります。
すべてVPTJ初版（Rev.00）の値です。`[X]` は「アドレスXに入っているポインタ」を表します。

## 試合中

| 内容 | アドレス | 備考 |
|---|---|---|
| 投手テーブル（試合用） | `0x020C0BE0` ＋ 側×`0x210` ＋ 投手番号×`0x2C` | 1人0x2Cバイト。`+0x04`〜`+0x0F`が変化球12枠（上位3bit＝Lv、下位5bit＝球種）、`+0x14`〜`+0x1B`が投手能力（byte86〜93）、`+0x1A`の上位4bitが第3球種セット |
| 野手テーブル（試合用） | `0x020C2360` ＋ 番号×`0x44` | 選手データと同じ並び（`+0x28`〜が野手能力） |
| 球種選択の構造体 | `[0x020D0E44]` | `+0`＝表示用の球種番号、`+1`＝球種コード（系統c：1種類目＝c、2種類目＝c＋7、スローボール＝6） |
| 今投げている投手のデータ | `[[0x020D0F0C]+8]` | 投手テーブルの該当行を指す |
| 最近の投球履歴 | 構造体`+0x2F6`〜`+0x2FA` | 表示用の球種番号を5球分 |
| キー入力 | `0x020BBF6C` | u16、+0＝押した瞬間、+2＝リピート |

## 選手能力の詳細画面・簡易カード

| 内容 | アドレス | 備考 |
|---|---|---|
| 詳細画面の管理構造体 | `0x020D0C74` | `+4`＝表示中の投手データ、`+0x34`＝カーソル行、`+0x18`＝カーソル列 |
| 特殊能力アイコンの表 | `0x020D0D70` | 8列×5行、u32 |
| 簡易カードの配列 | `[0x02193500]` ＋ 4 ＋ カード番号×`0xA4` | `+0x94`〜が変化球12枠 |

## ペナント

| 内容 | アドレス | 備考 |
|---|---|---|
| ペナントの構造体 | `[0x021B5E24]` | |
| 参加チームの選手データ | 構造体 ＋ `0x33F0` ＋ 枠番号×`0xA34` | |
| リーグのチームコード | 構造体 ＋ `0xF07` ＋（リーグ×6＋枠）×`0x308` | 上位4bitが`F`ならアレンジチーム。下位4bitは、初回セーブ前＝アレンジファイル番号、初回セーブ後＝枠番号（入れ替わりバグの原因） |

## ROMパッチで使っている領域

| 内容 | アドレス |
|---|---|
| 第三球種（人間操作）のコードと設定表 | ov3の拡張部分 `0x02147EC0`〜（設定表 `0x02147FF4`） |
| CPUの第三球種のコード・状態・設定表のコピー | ov10の未使用領域 `0x02192200`〜`0x021923E8` |
| ペナント修正の判定関数 | ov10 `0x021923F0` |
| 表示改善のコード | ITCM `0x01FFAC00`〜（起動時のコピー範囲を拡張） |
| ポップ解禁（縦変化の負の値を0に丸める命令） | ov10 `0x02169E40`（直前の比較は `0x02169E3C`） |
| 普通のストレートの表示（選手能力詳細） | ARM9 `0x020569F8` |
| 普通のストレートの表示（簡易カード） | ov10 `0x021590E4` / `0x0215920C` / `0x02159480` |
