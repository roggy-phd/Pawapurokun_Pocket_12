パワポケ12 第三球種パッチ v31unlimited

セット1〜E: 従来どおり追加50枠まで。
セットF: 追加189枠まで。初期値は通常27球種の各Lv7〜1。
オリジナル変化球は追加候補に含めない。超スローボールもLv1〜7を含む。
Fの初期値には通常ストレートのLv違いも含む。編集・削除可能。
「unlimited」は従来の50枠制限を解除した名称で、無限枠ではない。

使い方
Pythonで PowerPoke12_ThirdPitch_v31unlimited.py を起動すると編集画面が開く。
元ROMから作成する。適用済みv31への重ね掛けはしない。
CLI:
python PowerPoke12_ThirdPitch_v31unlimited.py original.nds patched.nds
保存済みJSONを使用する場合は --config v31unlimited_default.json を付ける。
--edition normal は旧通常版の初期セットに戻す（Fの189枠上限は維持）。
選手のbyte92上位ニブルがFなら拡張セットを使用。元の選手データ自体は変更しない。

構造と容量
既存56バイト刻みの配置は維持し、最後のFのみ56→195バイトに拡張。
全表840→979バイト（+139バイト）。表は3か所に複製される。
CPU用ov10表終端 0x02192DDB / 既存領域終端 0x02192E12: 残55バイト。
ov3追加終端（アライン前）0x0214849F / 制限0x02149D00。
ITCM追加終端（32バイト整列後）0x01FFBDC0 / ITCM終端0x01FFC000。
従来の球種参照ARMコードと抽選・読みコードは変更していない。
枠数はカテゴリ別のカウントから取得され、固定の50回走査ではない。
セット情報はROMに格納される。189枠分をセーブに新規保存する必要はない。

球種数の注意
189は追加表の枠数であり、「基礎12+189=201種類の独立球種」を意味しない。
通常27種類×7Lv=189組。その中には基礎球種と同じ組もある。
v31の既存仕様を維持: 各系統の先頭追加球は基礎との重複でも有効。
2個目以降の追加球は基礎2枠と同じ球種・Lvなら走査時に除外される。
追加表内の同じ球種・Lvの重複は入力時に禁止。
各系統は基礎2枠が埋まっている場合に追加球を使用する既存仕様。
左右による表示名（シンカー/スクリュー等）の扱いも従来どおり。

検証
元ROMから生成完了。ARM9/ov3/ov10/ov15/ov5/ov17は既存buildの
再展開一致検査を通過。ヘッダCRC維持。Python構文チェック通過。
Unicornによる実ARM命令実行で、アクション・CPU・表示の参照関数について
全189枠、末尾超過、E/F境界、基礎重複の591検査通過。
再検査: pip install unicorn ; python verify_v31unlimited.py
GUIの目視操作、melonDSの試合、DSi実機、オーペナ成績は未検証。

強さの注意
全Lvを追加すると低LvもCPU投球候補になる。Lvによる投球重みと打撃判定を
維持するので、従来最強Fより強いとは限らない。被読球率やプラトーも
この実装検証からは確定できない。低Lvを除く構成との比較が必要。
