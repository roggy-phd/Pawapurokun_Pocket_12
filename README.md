# pawapoke12-tools

『パワプロクンポケット12』（ニンテンドーDS、ゲームコード VPTJ）の選手パスワード／QRコード生成ツールと、ROMパッチ作成ツールです。

## 注意

- **このリポジトリにはゲームのROM、セーブデータ、エミュレータのステートセーブは含まれていません。** 各自が所有するゲームカードから吸い出したROMに対して使うことを前提としています。ROMの配布は違法です。
- ROMパッチ作成ツールは、改造していない初版ROM（`PAWAPOKE12_VPTJA4_00.nds`、SHA1 `4327f56f23729a59d44bd170e0ed53a2bb4667dd`）にだけ対応しています。
- 改造は自己責任でお願いします。セーブデータは必ずバックアップを取ってください。

## 内容

| フォルダ | 内容 |
|---|---|
| `password_tool/` | 選手パスワード／QR生成・解析ツール v1.60d（Python／Tkinter） |
| `rom_patcher/` | ROMパッチ作成ツール v31（通常版・max版、Python／Tkinter、標準ライブラリのみ） |
| `tools/` | melonDSのステートセーブを解析するチェッカー（パッチの動作確認用） |
| `docs/` | パスワードのバイト対照表、メモリ上のアドレス一覧、解析メモ、オーペナ検証の結果 |

## 動作環境

- Python 3.8以降（Windowsで確認）
- パスワードツールのQR出力には `qrcode` / `Pillow` が必要な場合があります（ツールの表示に従ってください）

## ROMパッチ作成ツール（v31）

```
python rom_patcher/PowerPoke12_ThirdPitch_v31.py            # ウィンドウで使う（通常版）
python rom_patcher/PowerPoke12_ThirdPitch_v31max.py         # ウィンドウで使う（max版）
python rom_patcher/PowerPoke12_ThirdPitch_v31.py 元.nds 出力.nds [--config sets.json | --edition normal|max] [オプション]
```

通常版とmax版は同じプログラムで、初期セットだけが違います。

### 追加球種（第三球種・第4球種以降）

- パスワードbyte92の上位4bit（1〜15）でセットを選びます。パスワード側の変更はありません。v28〜v29で作った選手もそのまま使えます。
- 1セットに最大50球（1行目の第三球種6枠を含む）。第4球種以降は、系統ごとの配分が自由です。
- 同じ球種でもLvが違えば複数持てます（同じ球種・同じLvの重複はエラー）。オリジナル変化球は追加できません。
- 各系統の1行目（第三球種）は、選手がすでに持っている球でも使われます。2つ目以降は、選手の枠と球種もLvも同じ球なら使われません。
- 追加球種が使えるのは、その系統の1番目と2番目の枠が両方埋まっている選手だけです。
- 人間：同じ方向を押すたびに 1番目 → 2番目 → 追加1 → … → 1番目。CPU：系統を決めた後、Lvの比で投げ分けます（アクション野球・オーペナとも）。
- 初期セット：通常版は 1〜7＝基本5系統の変化球Lv1〜7、E＝ストレートLv7、F＝カットボール／Dカーブ／チェンジアップ／Hシンカー／HシュートLv4＋ストレートLv7。max版はセットFに、スライダー系・カーブ系・フォーク系・シュート系・ストレート系の全球種をLv7。
- 設定はウィンドウで保存・読込できます（JSON。v30以前の形式も読めます）。

### 主な機能

| 機能 | 初期値 | コマンドライン |
|---|---|---|
| 追加球種（人間の操作） | 常にON | ― |
| CPU投手も追加球種を使う（アクション野球・オーペナ） | ON | `--no-cpu` で外す |
| 打者の読みの修正（原作バグ修正：投球履歴の番号の取り違え＋オーペナのサインバレ） | ON | `--no-read-fix` で外す |
| └ オーペナ：追加球種を、打者の読みでは別の球として扱う | ON | `--no-read-sep` で外す |
| 　└ 同じ球種でもLvが違えば別の球として読む | ON | `--read-type` で外す（同じ球種は同じ球） |
| 　└ ストレート系の追加球種もストレート待ちとは別の球にする | ON | `--straight-together` でまとめる |
| └ （上の「別の球」をOFFにした場合）v29の読み分け | ― | `--no-read-split` で外す |
| 選手能力詳細：特殊能力一覧のスクロール | ON | `--no-scroll` |
| 選手能力詳細：LRで変化球ページ切替（続き・追加球種を6球ずつ） | ON | `--no-pages` |
| 選手能力簡易カード：Yで投法欄⇔追加球種の最高Lv（系統ごとの位置固定） | ON | `--no-card` |
| パス／QR登録時の特殊能力統合の無効化 | すべて止める | `--merge off` / `--merge upgrade` |
| アクション野球：サブポジ○のメイン守備バグ修正 | OFF | `--subpos-fix` で有効化 |
| ペナント：セーブ後にアレンジチームの選手が入れ替わるバグ修正 | ON | `--no-pennant-fix` |
| アクション野球：オリ変の上方向の変化（ポップするストレート）を解禁 | ON | `--no-pop-unlock` |

アクション野球のCPU打者の読みは、追加球種を区別しません（その系統の1番目の球として扱います）。

過去の版（v28・v29・v30）は `rom_patcher/old/` に残しています。変更の詳細は `rom_patcher/CHANGELOG.md` を参照してください。

DSi実機（TWiLight Menu++ / nds-bootstrap）でもセーブできるよう、ROMヘッダのCRCを元のROMと同じ値に保っています（詳細は `rom_patcher/CHANGELOG.md` の v26e）。

## オーペナでの検証結果（ざっくり）

- **v28（原作の読みのバグそのまま）**：最強選手6人×16シーズンで、第三球種を足しても防御率は変わりませんでした（どの投手も0.7〜0.9）。
- **v31（読みのバグ修正＋追加球種を別の球）**：5シーズン。基本12球種＋セットF 50球の「62球種の最強F」が、防御率0.58・奪三振12.5/9で5シーズンすべて1位。他の最強5人は防御率0.95〜1.20で、最強Fとの差は有意でした（最強Eとはp=0.055）。
- 打者の読みのバグ（番号の取り違え・サインバレ）は、DS甲子園（初期版・ベスト版とも）の自動試合から同じ処理が引き継がれていたものです。

詳細は `docs/openpenna_verification.md` と、note記事③を参照してください。
