# パワポケ12 解析・改造ツール集（pawapoke12-tools）

『パワプロクンポケット12』（Nintendo DS、ゲームコード `VPTJ`）の選手パスワード／QRコード作成、ROMパッチ、ペナント成績の抽出と解析を目的とした非公式プロジェクトです。

このリポジトリは**ツールと解析資料**を公開するものであり、ゲームROM・セーブデータ・エミュレータのステートは配布していません。

## 収録内容

| ディレクトリ | 内容 |
|---|---|
| [`password_tool/`](password_tool/) | 選手パスワード／QRの生成・読み込み。パスワードツール v1.60d 系 |
| [`rom_patcher/`](rom_patcher/) | 第3球種以降の追加、CPUの配球・打者の読み、各種試合／ペナント処理の変更を行うROMパッチャー（v31系） |
| [`tools/`](tools/) | セーブ／ステートの解析ツール、動作検証ツールなど。ペナント成績CSV抽出ツールもこちらを参照 |
| [`docs/`](docs/) | パスワード仕様、アドレス・解析メモ、オーペナ検証結果など |

### はじめて使う方へ

- **選手パスワード・QRを作成したい**：`password_tool/`
- **自分のROMへ追加球種パッチを作成したい**：`rom_patcher/`
- **オーペナの成績をExcelで集計したい**：`tools/` のペナント成績CSV抽出ツール
- **内部仕様・検証結果を読みたい**：`docs/` および下記のnote記事

## 動作環境と注意事項

- Python 3.8以降。GUIはTkinterを使用。ツールごとに必要なライブラリが異なる場合があります。
- パスワード／QRツールでQR画像を出力する場合は、`qrcode` や `Pillow` などを別途インストールしてください（各ツールの案内に従ってください）。
- ROMパッチャーは**未改造の日本語初版ROM**（`PAWAPOKE12_VPTJA4_00.nds`、SHA-1：`4327f56f23729a59d44bd170e0ed53a2bb4667dd`）を前提としています。
- パッチ適用済みROMへの重ね掛けはしないでください。**必ず原ROMとセーブデータをバックアップ**してください。
- 各自が適法に入手・吸い出したデータを使用してください。改造による不具合への対応は保証されません。

## ROMパッチャー：v31系

v31系には通常版・max版・unlimited版・unlimited_original_plus版があります。GUIから設定できる項目が多いため、詳細は [`rom_patcher/`](rom_patcher/) と [`rom_patcher/CHANGELOG.md`](rom_patcher/CHANGELOG.md) を参照してください。

| 版 | 概要 |
|---|---|
| `PowerPoke12_ThirdPitch_v31.py` | 基本の追加球種パッチ |
| `PowerPoke12_ThirdPitch_v31max.py` | 第3球種などの初期セットを拡張した版 |
| `PowerPoke12_ThirdPitch_v31unlimited.py` | セットFの追加枠を最大189枠に拡張 |
| `PowerPoke12_ThirdPitch_v31unlimited_original_plus.py` | unlimitedにオリジナル変化球用の追加枠を搭載 |

通常版・max版は `rom_patcher/`、unlimited系は従来 `rom_patcher/v31unlimited/` に収録されています。**実際のファイル配置は各ディレクトリで確認してください。**

例（通常版）：

```bash
python rom_patcher/PowerPoke12_ThirdPitch_v31.py
```

引数なしではGUIを起動します。CLIからのROM入出力やJSON設定ファイルの利用については、各スクリプトのヘルプを参照してください。

### 第2球種枠の強度計算：2026年10月の重要な変更

原作ROMの `HenkaV`（overlay10、`0x02170580`）を調べると、第1球種側の選択コード0〜5では変化量・球速を参照する一方、**第2球種側の選択コード7〜12では基本強度0を返す分岐**が存在します。これに対し、第2枠でも実効変化量／球速を参照させるv31系の修正を設計・追加しました。

| 選択コード | 従来の `HenkaV` | 第2枠強度修正案 |
|---|---|---|
| 0〜4（第1変化球） | 実効Lvを参照（最大6） | 変更なし |
| 5（第1直球） | 球速などを参照 | 変更なし |
| 6 | 0 | 変更なし |
| 7〜11（第2変化球） | 0 | 対応する実効Lvを参照（最大6） |
| 12（第2直球） | 0 | 直球側の球速補正へ |
| 13以上 | 0 | 変更なし |

**重要：この変更は「第2球種だけを強化する別仕様」で、従来の原作準拠v31と同一条件ではありません。** 第3球種以降の既存処理とは区別し、比較実験では旧版・修正版を混在させないでください。また、全投手の第2球種に作用し得ます。

従来版は、旧版を保存したフォルダ（`before_second_slot_strength_fix/` など、リポジトリ内の実際の配置に従ってください）から取得できるようにする方針です。**2026-10-14時点で、修正パッチの実戦・オーペナによる第2枠強度の動作検証は未完了です。** ROM生成と実戦の確認は別です。

**コード配置について要再確認：** 既存の走者NULL参照ガードはov10の `0x021921C4` 周辺を使用しています。第2球種強度修正で同じアドレスを使う場合、両処理の重複・上書きを避けるために使用領域とROM生成後の命令列を必ず再検証してください。

### その他の主な変更点

- CPUにも追加球種を投げさせる処理、打者の「読み」の番号取り違え・サインバレ対策、Lv違いの球種を別扱いにする設定
- アクション野球の表示切替、投手の追加球種を確認する画面、特殊能力一覧のスクロール
- サブポジションや守備処理、走者の責任投手ポインタに関する対策
- オーペナの先発投手を救援候補に含める条件の変更（独立した①②③のオプション）
- ペナントでのアレンジチーム選手の保存／復元に関する対策

一部の修正はコード上の検査のみで、DSi実機・144試合の再現検証は未完了です。詳細なフックアドレスと修正履歴は [`rom_patcher/CHANGELOG.md`](rom_patcher/CHANGELOG.md) に整理しています。

## ペナント成績CSV抽出ツール

通常セーブ（`.sav`）およびmelonDSのステート（`.ml1`など）から、ペナントの**投手・打撃シーズン成績をCSV出力**するツールです。解析対象のセーブ形式・ゲーム版・スロットにより対応範囲が異なる場合があります。

- ペナントのセーブスロット①・②の選択／両方の一括抽出
- 球団名・選手名付きで投手成績／打撃成績を分けて出力
- 投手：登板、勝敗、投球回、奪三振、防御率、被安打、**四球と死球の内訳**、WHIP、K/BB、K/9、BB/9など
- 打撃：打席・打数・安打・本塁打・打点・打率・長打率など、解読済みのシーズン成績
- 通常セーブに保存されていない項目を推定で補完しません。WHIPでは死球を含めず、被本塁打のシーズン累計や厳密な被打率は未対応です。

**このツールは選手の基礎能力・特殊能力を編集するものではありません。** セーブデータを読み取り、CSVを生成するためのものです。導入・起動方法やバージョン固有の注意点は [`tools/`](tools/) のツール付属READMEを参照してください。

### シーズン成績レコードの一例

検証済みの投手シーズン記録は、1投手 `0x16`（22バイト）単位です。`+0x00`＝投球アウト数、`+0x02`＝奪三振、`+0x0A`＝四球、`+0x0B`＝死球、`+0x0C`＝登板数、`+0x0E`＝自責点（下位10bit）、`+0x10`＝残り有効スタミナ（下位12bit）、`+0x12`＝被安打（下位10bit）。このほか、勝敗・セーブ・HPなどを保持します。セーブ内の位置はデータ・スロットに依存します。

## 解析と検証について

このプロジェクトは、実機・melonDSでの検証、セーブ／RAMダンプ、ROMのARM命令の逆解析を組み合わせています。**ROMで分岐を確認した事実、パッチの静的生成結果、試合・オーペナでの実測結果を区別**して扱います。

オーペナの比較では、特殊能力「変化球中心」の有無や追加球種数による投手成績への影響も調べています。ただし、旧版と第2球種強度修正版では条件が異なるため、旧実験の結果を修正版の効果として扱わないでください。

詳細は [`docs/`](docs/) および以下の記事を参照してください。
